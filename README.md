# Leak Desk

An AI interrogation game for #OperationLeatherJacket. Every suspect is a live Claude character with a voice and a secret; the company AI helping you might be in on it.

Unity 6 · Claude Haiku 5.5 / Sonnet 5.5 · Fish Audio · Cloudflare Worker proxy (`Tools/worker`). Paid art packs (Synty, GUI Pro) and `LlmConfig.asset` are not included.
